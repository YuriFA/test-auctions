# SDD-041 Dark/Light Theme And App Header

## Статус

Запланировано.

## Цель

Добавить сквозную светлую/тёмную тему приложения и общую шапку сайта: слева — лого и название приложения «ГрузоТорг», справа — переключатель темы. По умолчанию тема берётся из системных настроек пользователя; явный выбор пользователя сохраняется между сессиями.

## Охват

- **Theme-инфраструктура** (новый слайс `src/shared/theme/`):
  - состояния `system | light | dark`;
  - чтение системной предпочтения через `matchMedia('(prefers-color-scheme: dark)')`;
  - применение темы добавлением/удалением класса `.dark` на `document.documentElement` (токены и `@custom-variant dark` уже заведены в SDD-004);
  - персистентность выбора пользователя в `localStorage` под ключом `theme`;
  - реакция на изменение системной предпочтения, пока выбрано `system`;
  - синхронизация выбора между вкладками через событие `storage`.
- **Предотвращение FOUC**: инлайн-скрипт в `index.html`, который до первой отрисовки React ставит класс `.dark` на `<html>` на основании сохранённого выбора или системной предпочтения.
- **Компонент переключателя темы** (`src/features/theme-toggle/`):
  - иконка солнце/луна из `lucide-react`;
  - доступная разметка: `aria-label`, корректный `role`/`aria-pressed` или эквивалент, видимая фокус-обводка, keyboard-activation;
  - cycle `system → light → dark → system` либо dropdown с тремя опциями — финализируется в реализации.
- **Шапка сайта** (новый `src/widgets/header/ui/header.component.tsx` или `src/app/layouts/header/`):
  - sticky-top, `border-b`, фон `bg-background`;
  - слева: лого из `public/favicon.svg` (переиспользовать SVG, не дублировать) + текстовый знак «ГрузоТорг»;
  - справа: переключатель темы;
  - встраивается в `RootLayout` (`src/app/layouts/root-layout.component.tsx`) над `<Outlet />`.
- **Обновить title приложения**: `<title>` в `index.html` привести в соответствие с названием «ГрузоТорг».

## Зависимости

- `SDD-004` — styling foundation: тёмные токены и `@custom-variant dark` уже присутствуют в `src/app/styles/index.css`.
- `SDD-005` — router and app providers: `RootLayout`, в который встаёт шапка.
- `SDD-038` — accessibility семантика: переключатель темы и навигационные элементы шапки подчиняются тем же правилам доступности.

## Критерии приёмки

- При первой загрузке без сохранённого выбора тема соответствует системной (`prefers-color-scheme`).
- При сохранённом выборе `light` или `dark` тема применяется до первой отрисовки React — без мигания светлого фона (no FOUC).
- Класс `.dark` на `<html>` и значение `localStorage.theme` консистентны между собой и между вкладками одного origin.
- Переключатель доступен с клавиатуры, имеет распознаваемый `accessible name`, объявляет текущее состояние скринридеру.
- Шапка присутствует на всех маршрутах приложения (`/auctions` и вложенные), не перекрывает контент и сохраняет sticky-поведение при скролле.
- Лого переиспользует существующий `favicon.svg`; отдельная копия SVG-контента в компоненте не допускается.
- `pnpm check` (`fmt:check && typecheck && lint && lint:fsd`) проходит без регрессий; добавленные e2e/tests (если есть) зелёные.

## Non-goals

- Полный ре-скининг существующих страниц: токены `bg-background`/`text-foreground` уже используются, дополнительная адаптация не требуется.
- Многоязычность и i18n-инфраструктура: название приложения зафиксировано как «ГрузоТорг», переключение языков вне scope.
- Глобальный brand-редизайн: визуал шапки ограничен минимальной sticky-разметкой и существующими токенами.
- Цветовые схемы кроме `light`/`dark` (например, акцентные «темы бренда»).

## Заметки и риски

- FOUC-скрипт должен выполняться синхронно в `<head>` до загрузки React-бандла; это единственное место, где читаем `localStorage` вне React-дерева.
- Слушатель `matchMedia` нужно снимать в `useEffect` cleanup, иначе утечка в HMR и при навигации.
- Переключатель темы должен корректно работать при SSR-less Vite SPA: можно работать с `document` напрямую, но все чтения — внутри эффектов, не в render-фазе, чтобы не ломать консистентность первого пэйнта с FOUC-скриптом.
- Название «ГрузоТорг» — продуктовой решение вне OpenAPI/требований; фиксируется здесь и в `decisions.md` (D-015), чтобы не плодить drift между `<title>`, шапкой и потенциальной будущей мета-разметкой.
