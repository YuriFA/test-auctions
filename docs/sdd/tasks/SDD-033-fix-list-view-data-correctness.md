# SDD-033 Fix List View Data Correctness

## Статус

Запланировано.

## Цель

Исправить фактические ошибки представления данных в списке аукционов, чтобы UI показывал ровно те значения, которые обещает контракт и бизнес-смысл.

## Охват

- Исправить отображение `price_per_km` в карточке списка:
  - убрать повторный расчёт `currentPrice / pricePerKm`;
  - рендерить либо готовое поле `price_per_km`, либо корректно переименовать/перестроить VM, чтобы semantics были недвусмысленны.
- Проверить и при необходимости переименовать поля VM, где имя сейчас провоцирует логическую ошибку (`pricePerKm`, `currentPrice`, related labels).
- Добавить regression-тесты на mapper и UI-рендер, которые доказывают корректность чисел в list card.
- Перепроверить остальные derived display values в списке на предмет похожих semantic mismatches.

## Зависимости

- `SDD-017`
- `SDD-019`
- `SDD-020`

## Критерии приёмки

- Карточка списка больше не вычисляет `цена за км` из уже готового поля `price_per_km`.
- Названия полей VM не вводят в заблуждение относительно того, является ли значение raw DTO field или derived metric.
- Unit-тесты покрывают happy-path и предотвращают возврат неверной формулы.
- E2E/visual assertions, где фигурирует цена в карточке, обновлены под корректную семантику.

## Non-goals

- Полный редизайн карточки списка.
- Изменение detail price presentation, если проблема локальна только списку.

## Заметки и риски

- Это не "косметика": неверные деньги на основном экране бьют по доверию к продукту сильнее большинства архитектурных огрехов.
